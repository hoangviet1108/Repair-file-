Dựng lại chỉ mục cho file Sony XAVC

Dùng khi file không mở được vì mất chỉ mục (máy tắt đột ngột, thẻ lỗi, copy hỏng). Cần một file tốt quay bằng cùng máy, cùng cài đặt (độ phân giải, tốc độ khung hình, bitrate) để làm mẫu.

Chưa chọn
3
Lưu file mới thành
Tự đặt cạnh file hỏng
Chọn file mẫu và file hỏng để bắt đầu.

Cách hoạt động

  1. Đọc chỉ mục của file mẫu để biết máy quay sắp xếp hình, tiếng và metadata thế nào.
  2. Quét file hỏng theo từng chu kỳ, đo kích thước từng khung hình, bỏ qua vùng bị xóa trống.
  3. Ghi một file mới gồm dữ liệu còn lại và chỉ mục dựng lại. File gốc giữ nguyên.

Cần ổ đĩa còn trống khoảng bằng dung lượng file hỏng. Phần dữ liệu đã bị xóa trống (byte FF) không thể lấy lại.
